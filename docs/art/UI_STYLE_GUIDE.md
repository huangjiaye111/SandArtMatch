# SandArtMatch 战斗 UI 风格规范草案

## 总体风格

方向：清爽沙画工坊。

UI 应该像轻量手作工具，而不是重装饰面板。所有控件优先支持快速判断：是否可点、是否选中、是否满桶、是否可合成、是否完成。

## 字体规范

### 中文字体

- 首选：系统默认无衬线，微信环境可使用 `PingFang SC`、`Microsoft YaHei`、`Noto Sans SC` 回退。
- 字形气质：圆润但清楚，不使用花体、手写体作为功能文字。
- 数字：建议使用同一无衬线字体，必要时为步数、数量使用半粗字重。

### 字号建议，以 750 x 1334 为基线

| 场景 | 字号 | 字重 | 用途 |
| --- | --- | --- | --- |
| 结果标题 | 48 到 56 | 700 | 成功、失败、完成 |
| 重要数字 | 40 到 48 | 700 | 步数、目标数量 |
| 主按钮文字 | 30 到 34 | 700 | 继续、确认 |
| 次按钮文字 | 26 到 30 | 600 | 重开、返回 |
| 顶部状态文字 | 24 到 28 | 600 | 目标、回合信息 |
| 辅助说明 | 20 到 24 | 500 | 短提示 |

## 间距规范

| Token | 数值 | 用途 |
| --- | --- | --- |
| `space-4` | 4 px | 图标内部微调 |
| `space-8` | 8 px | 小控件内边距 |
| `space-12` | 12 px | 图标与数字间距 |
| `space-16` | 16 px | 小按钮组间距 |
| `space-24` | 24 px | 面板内容间距 |
| `space-32` | 32 px | 大模块间距 |
| `space-48` | 48 px | 结果面板上下留白 |

布局要求：

- 可点击按钮最小热区建议 88 x 88。
- 战斗主按钮高度建议 88 到 104。
- 结果面板主按钮宽度建议 320 到 420，高度 92 到 104。
- 桶与桶之间留出至少 16 px 视觉缝隙，避免误读为一个容器。

## 圆角规范

| 元素 | 圆角 |
| --- | --- |
| 小图标按钮 | 20 到 24 px |
| 主按钮 | 28 到 32 px |
| 结果面板 | 32 px |
| 槽位底座 | 18 到 24 px |
| 桶身外轮廓 | 根据造型，底部 20 到 28 px |
| 传送带模块 | 16 到 20 px |

注意：如果代码侧使用九宫格图，圆角需要在美术切图阶段固定，不在运行时叠加过多遮罩。

## 描边规范

| 元素 | 默认描边 | 状态描边 |
| --- | --- | --- |
| 桶身 | 3 px `#6E7A74`，透明度 70% | 选中 4 px `#48A7F8` |
| 槽位 | 2 px `#B8C0BA` | 可放置 3 px `#48A7F8` |
| 主按钮 | 无或 2 px 深色边 | 按下态使用内阴影 |
| 结果面板 | 3 px `#FFFFFF` + 2 px 浅灰外边 | 成功时顶部暖金装饰线 |
| 沙层 | 通常不描边 | 深色沙可加 1 到 2 px 顶部亮边 |

## 阴影规范

阴影必须轻，主要用于层级，不用于制造写实厚度。

| 层级 | 阴影 |
| --- | --- |
| 桶/槽位 | `0 6 0 rgba(38,48,45,0.12)` 或等价贴图 |
| 按钮 | `0 6 0 rgba(34,141,130,0.35)`，按下减少到 2 px |
| 面板 | `0 16 40 rgba(24,31,29,0.22)` |
| 顶部状态栏 | 可无阴影，或极轻 `0 4 12 rgba(24,31,29,0.10)` |

微信性能建议：

- 优先用预烘焙阴影切图。
- 避免大量实时模糊阴影。
- 避免多层半透明面板叠加。

## 按钮视觉状态

正式状态命名统一使用 `Normal`、`Pressed`、`Disabled`、`Selected`。中文说明可使用默认、按下、禁用、选中，但资源命名和交付表使用英文状态名。

### 主按钮

| 状态 | 视觉 |
| --- | --- |
| Normal | 活力青绿底，白色文字，底部 6 px 深色压边 |
| Pressed | y 位移 3 到 4 px，底部压边缩短，亮度降低 |
| Disabled | 雾灰底，文字白色透明度 70%，无压边或压边很浅 |
| Selected | 保持 Normal 底色，增加天蓝外圈或右上角小选中标记 |
| 加载 | 保持按钮尺寸，文字替换为简短状态或小型旋转图标 |

### 次按钮

| 状态 | 视觉 |
| --- | --- |
| Normal | 白色或浅灰底，炭黑文字，2 px 浅灰描边 |
| Pressed | 背景略深，内阴影 |
| Disabled | 透明度 55%，不可播放亮效 |
| Selected | 天蓝描边或角标，按钮尺寸不变 |

## 槽位视觉状态

| 状态 | 视觉 |
| --- | --- |
| 空槽 | 浅台面灰底，虚线或浅描边，内部有低透明度桶影 |
| 可放置 | 天蓝描边，槽底亮度提升 |
| 已占用 | 槽位弱化，桶本身成为主要视觉 |
| 锁定 | 斜纹浅灰覆盖，锁图标小而清楚 |
| 错误 | 珊瑚红短闪，不改变槽位常驻色 |

## 桶视觉状态

| 状态 | 视觉 |
| --- | --- |
| 空桶 | 透明桶身，底部轻阴影，内部空白清楚 |
| 部分桶 | 沙层块状清楚，顶部边缘略弧，颜色之间无复杂混合，填充高度清楚 |
| 满桶 | 桶口附近增加细线标记或小满格符号 |
| 选中 | 桶身上浮，天蓝外描边，桶口软白高光 |
| 可合成 | 暖金短脉冲，三桶之间可出现短连线 |
| 被吸沙 | 吸嘴方向出现短沙流线，源桶顶部沙层下降 |
| 禁用 | 桶身整体降饱和，透明度降低，叠加轻斜纹或锁符号，不改变沙色顺序 |

## 结果面板状态

| 状态 | 视觉 |
| --- | --- |
| 成功 | 暖金标题点缀，结果沙画居中，主按钮高亮 |
| 失败 | 标题使用炭黑，珊瑚红仅用于小警示，不大面积铺红 |
| 新记录/高评价 | 小型暖金徽章，避免盖住结果图 |
| 继续中 | 面板保持固定尺寸，按钮进入加载态 |

## 动效规范

- 单次点击反馈：80 到 140 ms。
- 桶选中上浮：120 到 180 ms。
- 吸沙过程：按玩法节奏走，视觉沙流不超过路径宽度的 1.5 倍。
- 合成成功：300 到 500 ms，局部高光即可。
- 结果面板弹出：180 到 260 ms，缩放从 0.96 到 1.0，透明度从 0 到 1。

## 750 x 1334 安全布局

- 顶部安全区预留：至少 24 px，异形屏可扩展。
- 底部安全区预留：至少 34 px。
- 左右边距：主内容建议 32 px，操作区可压到 24 px。
- 核心桶点击热区不得被装饰物覆盖。
- 结果面板宽度建议不超过 660 px，保留两侧呼吸空间。

## 禁止项

- 禁止把说明文字放在战斗主界面长期占位。
- 禁止用复杂背景图解释玩法。
- 禁止让装饰高光覆盖沙层颜色。
- 禁止让点击状态只靠微弱亮度变化表达。
- 禁止在结果面板里引入商店、签到、广告、排行榜或多关卡入口。
