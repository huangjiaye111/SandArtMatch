# SandArtMatch 核心战斗资产清单草案

## 资产生产原则

- 仅覆盖战斗内核心资产，不扩展商店、签到、广告、排行榜或多关卡界面。
- 所有资产应可落地到 Cocos Creator 3.8.8，但当前规划目录不修改 Cocos 项目。
- 优先使用 PNG/WebP、九宫格、SpriteFrame、简短序列帧。
- 不依赖复杂粒子、高成本 Shader 或大量实时模糊。
- 所有正式资产必须原创或有明确授权来源。

## 命名建议

正式资源命名用于 TASK017 交付和后续导入参考，不在当前阶段创建 `.meta`。

格式：

`battle_[category]_[name]_[state]`

状态命名：

- 按钮：`normal`、`pressed`、`disabled`、`selected`。
- 桶：`empty`、`partial`、`full`、`disabled`、`selected`。
- 槽位：`empty`、`available`、`occupied`、`locked`、`error`。

示例：

- `battle_bucket_clear_default`
- `battle_slot_bucket_available`
- `battle_button_primary_pressed`
- `battle_panel_result_success`

## 目录与导出格式

TASK017 首批资源建议按以下目录交付，后续导入 Cocos 时再生成 `.meta`：

- `art/source/battle/`: 可编辑源文件，PSD、Krita、Figma 或分层 PNG。
- `art/export/battle/ui/`: 按钮、面板、槽位、状态反馈 PNG。
- `art/export/battle/bucket/`: 桶身、桶口、遮罩、刻度、阴影 PNG。
- `art/export/battle/sand/`: 沙层基础形、顶部弧线、纹理叠层 PNG。
- `art/export/battle/conveyor/`: 传送带、方向箭头、吸沙嘴、吸沙流线 PNG。
- `art/export/battle/background/`: 750 x 1334 背景 PNG 或 WebP。

导出要求：

- UI 与桶类资产优先导出透明 PNG，按 1x 设计基线交付。
- 大面积背景可导出 PNG；确认微信包体压力后可另存 WebP。
- 九宫格资产必须提供建议切线或留边说明，圆角和阴影在切图中预烘焙。
- 普通沙层和普通桶优先使用灰白基础纹理加运行时 Tint。
- 桶内沙量使用 Mask 或裁剪区域连续填充，不为每个容量制作独立切图。
- 通用面板、按钮和承托底板使用九宫格，不使用多套固定尺寸切图。

## 交付检查

- 资产是否能在 750 x 1334 下保持清楚。
- 沙色是否在透明桶内仍可辨。
- 桶的空、部分、满、禁用、选中、可合成是否一眼能区分。
- 按钮状态是否不依赖文字也能判断。
- 半透明叠层数量是否可控。
- 是否存在未授权素材或过度参考其他游戏的界面细节。
